# EOS & GAIA — site atualizado

Arquivos principais:
- `index.html`: página inicial com nova seção Rentabilidade.
- `ico2.html`: página interativa da carteira EOS com seletor de k.
- `ise.html`: página interativa da carteira GAIA com seletor de k.
- `assets/js/finor-data.js`: dados gerados a partir dos CSVs/JSONs locais.
- `assets/js/dashboard.js`: lógica dos seletores, toggles, gráficos e treemap.

Abra `index.html` no navegador ou suba a pasta inteira em um servidor estático.
